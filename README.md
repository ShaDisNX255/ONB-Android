# ONB-Android

Unofficial Android port of OpenNetBattle.

This project provides Android builds of OpenNetBattle and contains Android-specific features and changes intended to make the game work well on Android devices.

## Downloads

Android builds are distributed through the **Releases** section of this repository.

The Android port uses its own version numbering, separate from the OpenNetBattle game version. For example, Android `v1.0.0` may be based on OpenNetBattle `2.1.7`.

## Source Code

The OpenNetBattle source code is not currently available for public distribution.

Because of this, this repository currently hosts Android releases only. The Android source is intended to be published here once permission allows it.

## Status

This is an **unofficial Android port**.

Android-specific development, versioning, updates, controls, and other platform features are maintained separately by me.

ONB is created and maintained by Team Frameskip.
